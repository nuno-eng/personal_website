# Nuno Fontoura – Operations Consultant & Business Coach

Personal website for Nuno Fontoura, founder of NabiaEdge. Built to convert founder-led businesses into strategic coaching clients through clear positioning and proven operational expertise.

## Pages

- **Home** (`index.html`) — Introduction, background, service offerings, and social proof
- **Business Advisory** (`advisory.html`) — Deep dive into the flagship coaching programme, methodology, and client qualifications

## Features

- Clean, professional design using the Industry design system
- Mobile-responsive layouts
- Fast-loading standalone HTML files (no external dependencies except design system assets)
- Strategic CTAs for booking consultation calls
- Social proof via testimonials and media features

## Content Sections

### Home Page
- Hero section with founder positioning
- Problem statement (founder outgrowth)
- Background across Marines, Amazon, and NabiaEdge
- Two service tracks: Micro-consulting and Business Advisory
- MSN feature callout
- Client testimonials
- Final conversion CTA

### Business Advisory Page
- Programme overview and target audience
- The Vessel Operating System (proprietary web app)
- Four-step methodology: current state → gaps → plan → tracked execution
- Deliverables breakdown
- Clear qualification criteria (who it's for / not for)
- Client testimonials
- Strategic CTA

## Design System

This site uses the **Industry design system** — steel-blue accent on a light technical ground, Barlow typeface, and wireframe blueprint styling. All components are sourced from the design system bundle.

## Deployment

See `DEPLOYMENT_GUIDE.md` for step-by-step instructions on deploying to GitHub + Cloudflare.

### Quick Start
1. Export both Design Components as standalone HTML
2. Push to GitHub repository
3. Enable GitHub Pages
4. Point Cloudflare DNS to GitHub Pages
5. Enable SSL/TLS
